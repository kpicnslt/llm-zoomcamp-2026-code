# Решение ДЗ — Модуль 01: Agentic RAG

Решение домашнего задания `cohorts/2026/01-agentic-rag/homework.md`.

## Файлы

- `rag_helper.py` — адаптированный `RAGBase` под схему уроков (`filename`/`content`),
  `llm()` отдаёт весь ответ, `rag()` возвращает `RAGResult(answer, input_tokens, output_tokens)`.
- `solution.py` — полный прогон Q1–Q6.

## Как запустить

```bash
uv add gitsource minsearch openai toyaikit python-dotenv
# создайте .env c OPENAI_API_KEY=sk-...
uv run python solution.py
```

> Для Q3, Q5, Q6 нужны ключ OpenAI и доступ в интернет (модель `gpt-5.4-mini`).
> Для Q1, Q2, Q4 — только доступ в интернет (скачивание уроков через `gitsource`).

### Пометки о точности

- **Q1 и Q4** посчитаны детерминированно по содержимому репозитория и совпадают
  с вариантами 72 и 295 точно.
  > Нюанс: ДЗ фиксирует коммит `8c1834d`; локальная копия может отличаться на пару
  > файлов, но ближайший вариант остаётся прежним (72 / 295).
- **Q3, Q5, Q6** зависят от реального ответа API (число токенов и решения модели
  варьируются между прогонами). Указаны ближайшие из предложенных вариантов;
  `solution.py` печатает фактические значения при запуске с ключом.

## Что именно делали по шагам

1. **Preparation** — `GithubRepositoryDataReader` тянет `*.md` под `/lessons/`
   с коммита `8c1834d`; `file.parse()` → `{'filename', 'content'}`.
2. **Q1** — `len(documents)`.
3. **Q2** — индекс minsearch (`content` — text, `filename` — keyword), `index.search(QUERY)`.
4. **Q3** — RAG поверх индекса; переписаны `search` и `build_context` под новую схему,
   `llm`/`rag` доработаны под чтение `usage.input_tokens`.
5. **Q4** — `chunk_documents(documents, size=2000, step=1000)`.
6. **Q5** — тот же RAG, но индекс по чанкам; сравнение входных токенов с Q3.
7. **Q6** — `toyaikit`: инструмент `search` (схема из type hint + docstring),
   `OpenAIResponsesRunner.loop(...)`, подсчёт `function_call` с `name == "search"`.
